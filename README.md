# Image Gallery – CodeAlpha Internship

## About the Project

This Image Gallery is a responsive web application developed as part of my Frontend Development Internship at CodeAlpha.

The project showcases a collection of photographs with interactive features and a clean, modern design.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive image gallery layout
- Category-based image filtering
- Interactive image hover effects
- Lightbox image preview
- Next and Previous image navigation
- Keyboard navigation using arrow keys
- Responsive design for different screen sizes

## Project Structure

- `index.html` – Website structure
- `style.css` – Styling and responsive layout
- `script.js` – Interactive functionality
